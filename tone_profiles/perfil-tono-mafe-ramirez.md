## Patrones de escritura

### Estructura típica de un post

1. **Apertura emocional o personal** — Inicia desde una emoción explícita: orgullo, emoción, gratitud, reflexión o aprendizaje.
2. **Contexto del momento** — Explica el evento, experiencia, charla, viaje o hito que origina el post.
3. **Reflexión humana o de industria** — Conecta el hecho con confianza, liderazgo, innovación, inclusión financiera, fraude o comunidad.
4. **Reconocimiento a personas y equipos** — Agradece a compañeros, aliados, líderes, speakers, fundaciones o participantes.
5. **Insight principal** — Resume el aprendizaje en una frase potente o takeaway.
6. **Cierre cálido y directo** — Finaliza con gratitud, invitación, emoción o continuidad.

### Elementos de formato

| Elemento | ¿Lo usa? | Notas |
|----------|----------|-------|
| Emojis | ✅ Sí | Usa emojis para emoción y énfasis: 🚀🚀, :) !!, ♥️ |
| Hashtags | ❌ No | No aparecen como recurso habitual |

| Listas numeradas | ❌ No | No usa listas numeradas como formato dominante |

| Links | ✅ Sí | Incluye links de registro cuando invita a eventos |

### Longitud

- **Posts cortos**: 90–150 palabras, usualmente para invitaciones o anuncios.
- **Posts medios**: 180–280 palabras, para eventos, aprendizajes o agradecimientos.
- **Posts largos**: 320–500 palabras, cuando reflexiona sobre liderazgo, confianza o industria.
- **Promedio estimado:** ~240 palabras por post.
