## Priority Issues

### [P1] Visual system diverged from DESIGN.md
The live CSS is a purple/glassmorphism/Inter system. DESIGN.md specifies amber accent oklch(0.78 0.17 65), near-black surface oklch(0.10 0.012 265), GeistPixelSquare/GeistPixelGrid fonts, flat calendar cells. Complete swap.
**Fix:** Restore DESIGN.md token system. Replace Inter with documented Geist fonts. Change accent. Strip backdrop-filter from standard elements, reserve for modals only. Remove floating orbs.
**Command:** /impeccable polish app/globals.css app/page.tsx

### [P1] Silent API failures
All three API call sites use `.catch(() => {})`. Silent failure on save shows success indicator while data not persisted.
**Fix:** Add toast system. Surface errors with message + retry CTA. Never show success until request confirmed.
**Command:** /impeccable harden app/page.tsx

### [P1] WCAG AA compliance failures
--text-secondary on glass surfaces estimated 3.8:1 (below 4.5:1 floor). SVG icon buttons have no aria-label. Orbs not aria-hidden. Color is sole state indicator in date picker. Disabled inputs removed from focus without announcement.
**Fix:** Audit all text/bg pairs. Add aria-label to icon buttons. aria-hidden on orbs. Non-color indicators on selected states.
**Command:** /impeccable audit app/page.tsx

### [P2] Modal cognitive overload
Create/edit modal presents 5 decisions simultaneously. PostCreator has 8 fields + 4 numbered steps. All groups have identical visual weight.
**Fix:** Split modal into two focused steps, or use progressive disclosure. Remove numbered scaffolding from PostCreator.
**Command:** /impeccable layout app/page.tsx

### [P2] Zero power-user acceleration
No keyboard shortcuts. No bulk selection. No duplicate-event. DateRangePicker has no arrow key support.
**Fix:** N to create, E to edit, Escape to close, arrows to navigate months. Duplicate-to-country action on events.
**Command:** /impeccable harden app/page.tsx
